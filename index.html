Work — & where to find me

YouTube GitHub LinkedIn

I work with Globalion Technology Solutions, where I build and ship production AI-agent tooling. My focus is designing pluggable "skills" — small, self-contained MCP services that plug into larger agent platforms — and the infrastructure that hosts them.

I've shipped several live skills used inside the company's assistant platform, covering messaging automation, scheduled tasks, document retrieval, and anonymous web fetching. Alongside the skills, I've worked on the deployment stack behind them: containerised services on Hetzner, fronted by Cloudflare tunnels, with OAuth and Stripe-metered billing wired in end-to-end.
